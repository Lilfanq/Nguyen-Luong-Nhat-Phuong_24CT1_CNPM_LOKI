@startuml LOKI_OAuth
title LOKI - Đăng nhập OAuth bằng Google/Discord
actor "User | Người dùng" as User
boundary "FR | LOKI Frontend\nfrontend/src/features/auth/AuthFormPanel.jsx\nfrontend/src/App.jsx\nfrontend/src/features/auth/authService.js" as FR
control "BE | Supabase Auth / OAuth (managed)\nclient: frontend/src/supabaseClient.js" as BE
database "DB | Supabase / Loki-Hardware-Configurator\nproject ref: ynccytvbcsfutwstwmjr\nPostgreSQL: postgres\nauth.users / public.app_users" as DB

User -> FR : Chọn Google hoặc Discord
FR -> BE : GET /auth/v1/settings (authService.js)
BE --> FR : external[provider] = true
FR -> BE : supabase.auth.signInWithOAuth({ provider, options })
BE --> User : Redirect tới màn consent Google/Discord
User -> BE : Chấp thuận; callback về /auth/v1/callback
BE -> DB : Tìm/tạo danh tính trong auth.users
alt OAuth identity hợp lệ
  DB --> BE : user_id + provider metadata
  opt Trigger đã cài (backend/supabase/admin_roles.sql)
    DB -> DB : AFTER INSERT: tạo public.app_users
  end
else Provider từ chối hoặc identity không hợp lệ
  DB --> BE : Auth error / không tạo identity
end
BE --> FR : Session/JWT hoặc lỗi OAuth
FR -> BE : getAccountRole(user.id)
BE -> DB : SELECT public.app_users WHERE id = user_id
DB --> BE : Role theo RLS (nếu role row tồn tại)
BE --> FR : Trả role; FR mở workspace
FR --> User : Hiển thị trạng thái đăng nhập

note over BE,DB
  BE là Supabase Auth managed; repo không có server OAuth riêng.
  Trigger source: backend/supabase/admin_roles.sql.
  DB path: project Loki-Hardware-Configurator / postgres / auth.users và public.app_users.
  Supabase callback: https://ynccytvbcsfutwstwmjr.supabase.co/auth/v1/callback
  App redirect allowlist: GitHub Pages URL hoặc http://localhost:5173/.
  Google và Discord đã được bật; người dùng xác nhận đăng nhập thành công.
end note
@enduml
