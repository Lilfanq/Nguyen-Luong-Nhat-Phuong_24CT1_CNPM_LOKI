@startuml LOKI_WebHID
title LOKI - Kết nối thiết bị HID được hỗ trợ
actor "User - Người dùng" as User
boundary "FR - LOKI Frontend\nApp.jsx / DeviceCatalogPanel.jsx" as FR
control "BE - Supabase PostgREST\n(chỉ nhận inventory sau khi HID kết nối)" as BE
database "DB - Supabase PostgreSQL\nproject ref: ynccytvbcsfutwstwmjr\npublic.user_devices" as DB

User -> FR : Chọn kết nối thiết bị
activate FR
alt WebHID không khả dụng hoặc origin không an toàn
  FR --> User : Yêu cầu Chrome/Edge và HTTPS
else WebHID khả dụng
  FR -> FR : navigator.hid.getDevices()
  alt Đã có thiết bị được hỗ trợ và được cấp quyền trước đó
    FR -> FR : Mở thiết bị đã cấp quyền
  else Chưa có thiết bị được cấp quyền
    FR -> FR : navigator.hid.requestDevice({ filters: [] })
    FR --> User : Trình duyệt mở hộp thoại xin quyền
    alt Người dùng chọn thiết bị được hỗ trợ
      User --> FR : Chọn thiết bị
      FR -> FR : device.open()
    else Người dùng hủy hoặc từ chối quyền
      User --> FR : Hủy / từ chối quyền
      FR --> User : Hiển thị trạng thái đã hủy/bị chặn
    end
  end
  opt Thiết bị đã kết nối
    FR -> FR : Lưu lịch sử localStorage nếu đã đăng nhập
    opt User đã đăng nhập và migration user_devices đã áp dụng
      FR -> BE : Gửi metadata model (VID/PID/tên/loại; không serial)
      BE -> DB : UPSERT public.user_devices (RLS theo user_id)
      DB --> BE : Lưu thành công hoặc lỗi schema/quyền
      BE --> FR : Kết quả đồng bộ inventory
      FR -> FR : Hiển thị trạng thái lưu cloud hoặc chỉ lưu browser
    end
    FR --> User : Hiển thị workspace thiết bị
  end
end
deactivate FR
note over FR,DB
  WebHID chạy trực tiếp giữa browser và thiết bị; Supabase không scan hay điều khiển HID.
  Sau khi kết nối, user đăng nhập mới ghi metadata model vào public.user_devices.
  Device settings và button mappings vẫn ở browser storage.
  Device history được ghi localStorage khi user đăng nhập; guest không ghi history kết nối.
  Chỉ model được App.jsx nhận diện là hỗ trợ mới được lưu inventory.
end note
@enduml
