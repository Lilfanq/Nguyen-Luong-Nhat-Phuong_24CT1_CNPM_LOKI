title LOKI - Đăng nhập bằng email
actor "User | Người dùng" as User
boundary "FR | Frontend (trình duyệt)\nfrontend/src/App.jsx\nfrontend/src/features/auth/AuthFormPanel.jsx" as FR
control "BE | Supabase Auth / PostgREST\nDịch vụ Supabase quản lý" as BE
database "DB | Supabase PostgreSQL: postgres\nProject: ynccytvbcsfutwstwmjr\nBảng: auth.users, public.app_users,\npublic.user_profiles" as DB

note right of BE
  Supabase Auth: xử lý signInWithPassword; xem Authentication > Users.
  PostgREST: API truy vấn bảng khi frontend lấy role.
  Xem lời gọi: frontend/src/features/auth/authService.js.
  Quan sát request trong trình duyệt: Network > auth/v1 hoặc rest/v1.
  Đây là dịch vụ Supabase quản lý, không phải file server trong repo.
end note

User -> FR : Nhập email, mật khẩu; chọn Đăng nhập
FR -> FR : Loại bỏ khoảng trắng; kiểm tra dữ liệu rỗng
note right of FR
  Nếu email hoặc mật khẩu rỗng: báo lỗi và dừng,
  không gửi yêu cầu đến Supabase.
  Luồng tiếp theo giả định đã nhập đủ thông tin.
end note

FR -> BE : signInWithPassword({ email, password })
BE -> DB : Tra cứu danh tính trong auth.users
alt Xác thực thất bại
  DB --> BE : Không tìm thấy hoặc trả dữ liệu xác thực
  BE -> BE : Xác minh thất bại; chuẩn bị lỗi Auth
else Xác thực thành công
  DB --> BE : Dữ liệu xác thực của tài khoản
  BE -> BE : Xác minh thành công; tạo session
end
BE --> FR : result.error hoặc result.data.user và session
FR -> FR : Kiểm tra error và user
note right of FR
  error có giá trị: lưu lỗi đăng nhập.
  Không lỗi nhưng user rỗng: lưu lỗi không nhận được tài khoản.
  Không lỗi và có user: lấy role, cập nhật trạng thái đăng nhập.
end note

opt Không có lỗi và có user
  FR -> BE : Đọc role qua PostgREST theo user.id
  BE -> DB : SELECT role FROM public.app_users (RLS)
  DB --> BE : Role, không có dòng hoặc lỗi
  BE --> FR : Kết quả truy vấn role
  FR -> FR : Dùng role admin/user; lỗi thì dùng user
  FR -> FR : Gộp dữ liệu phiên khách với localStorage; cập nhật session UI
  opt Có user hiện tại và profile để đồng bộ
    FR -> BE : Gửi profile qua PostgREST (bất đồng bộ)
    BE -> DB : UPSERT public.user_profiles (RLS)
    DB --> BE : Kết quả hoặc lỗi
    BE --> FR : Kết quả đồng bộ
  end
end
FR --> User : Cập nhật giao diện theo kết quả

  public.app_users: backend/supabase/admin_roles.sql.
  public.user_profiles: backend/supabase/migrations/202610090001_user_profiles.sql.
  Profile còn được tải riêng bởi useEffect; thứ tự tải/ghi cloud không bảo đảm.
  Đồng bộ cloud phụ thuộc migration, quyền RLS và trạng thái triển khai.
end note
