User -> FR : Gửi yêu cầu đổi profile hoặc button mapping
FR -> BE : supabase.functions.invoke('loki-chat')
BE -> BE : Xác minh JWT, giới hạn request, gọi LLM
alt Edge Function hoặc LLM gặp lỗi
  BE --> FR : Trả lỗi service / timeout
  FR --> User : Hiện thông báo; không đổi cấu hình
else Nhận được câu trả lời và actions
  BE --> FR : reply + actions
  FR -> FR : validateAssistantAction(action, rules)
  alt Action không hợp lệ
    FR --> User : Bỏ qua action và nêu lý do
  else Action hợp lệ
    FR -> FR : Cập nhật profile/button mapping trong app
    opt Tạo/chuyển profile và cloud sync khả dụng
      FR -> DB : UPSERT public.user_profiles (user_id, name)
      DB --> FR : Thành công hoặc lỗi đồng bộ
    end
    FR --> User : Hiện câu trả lời và kết quả thao tác
  end
end
