@startuml LOKI_Admin
title LOKI - Quản lý vai trò quản trị
actor "User - Người gọi" as User
boundary "FR - AdminDashboard.jsx" as FR
control "BE - Supabase PostgREST / RPC" as BE
database "DB - Supabase\nLoki-Hardware-Configurator\nproject ref: ynccytvbcsfutwstwmjr\npublic.app_users" as DB

User -> FR : Mở trang quản trị
FR -> BE : listAccountsForAdmin()
BE -> DB : SELECT public.app_users (JWT)
DB -> DB : Áp dụng RLS theo vai trò
alt Người gọi có vai trò admin
  DB --> BE : Danh sách tài khoản
  BE --> FR : Trả danh sách
  FR --> User : Hiển thị danh sách
  User -> FR : Chọn vai trò mới
  FR -> BE : updateAccountRole(userId, role)
  BE -> DB : rpc(set_loki_user_role)
  DB -> DB : Kiểm tra admin; kiểm tra mục tiêu; UPDATE role
  alt Vai trò hợp lệ và người dùng đích tồn tại
    DB --> BE : Đã lưu thay đổi
    BE --> FR : Thành công
    FR --> User : Cập nhật vai trò
  else Không phải admin, tự đổi vai trò, dữ liệu sai hoặc không tìm thấy người dùng
    DB --> BE : Từ chối thay đổi; trả lỗi RPC
    BE --> FR : Trả lỗi
    FR --> User : Hiển thị lỗi; giữ vai trò cũ
  end
else Người gọi không có vai trò admin
  DB --> BE : RLS chỉ trả bản ghi chính chủ
  BE --> FR : Không có danh sách quản trị
  FR --> User : Từ chối quyền quản trị
end
note over FR,DB
  Supabase là backend managed; không có server Node/Express riêng.
  public.app_users được bảo vệ bởi RLS và RPC SECURITY DEFINER.
end note
@enduml
